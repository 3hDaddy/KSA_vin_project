01

프로젝트 개요

중고차 구매자가 겪는 정보 불균형 문제를 기술로 해결합니다.

🔍

문제 정의

중고차 구매 시 차량 이력 정보를 딜러에게만 의존해야 하며, 신뢰할 수 있는 독립적 확인 수단이 없습니다. 국내 공공 API는 존재하지만 일반인이 활용하기 어렵습니다.

Pain Point
🎯

타겟 사용자

생애 첫 중고차 구매를 앞둔 30대 일반인. 차량 지식이 부족하고 딜러의 설명을 검증할 방법이 없어 불안감을 느끼는 구매 예정자.

페르소나 A
✅

솔루션

VIN(차대번호) 17자리만 입력하면 사고이력·소유자이력·주행거리·리콜 정보를 즉시 조회할 수 있는 웹서비스. NHTSA 공공 API로 실데이터를 무료 제공합니다.

MVP 완성

02

주요 기능

VIN 하나로 조회할 수 있는 6가지 핵심 정보와 종합 신뢰 점수를 제공합니다.

🔎

VIN 조회 & 유효성 검사

17자리 ISO 3779 규격 VIN 실시간 검증. 잘못된 형식 즉시 안내, 허용 문자 자동 필터링.

✓ 완료
🚗

차량 기본정보

제조사·모델·연식·트림·엔진·연료 유형을 VIN 디코딩으로 자동 추출.

🔵 NHTSA 실데이터
⚠️

리콜 정보

해당 차량 모델에 발행된 리콜 목록과 미완료 리콜 여부를 실데이터로 확인. 미완료 리콜은 빨간색으로 강조 표시.

🔵 NHTSA 실데이터
🛡️

사고 이력

보험 처리 횟수, 수리 부위, 추정 수리비를 표시. 복수 사고 시 위험 배너 자동 노출.

🔘 Mock (국내 API 연동 예정)
👤

소유자 이력

명의 변경 횟수와 렌트·영업용 여부를 타임라인으로 시각화. 렌트·영업용 이력은 주황색으로 강조.

🔘 Mock (국내 API 연동 예정)
📊

종합 신뢰 점수

사고·소유자·리콜 항목을 종합한 0–100 점수. 링 애니메이션 게이지와 항목별 분해 바로 시각화. 우수·양호·주의·위험 4단계 등급.

✓ 완료

05

수강 후기

KSA 바이브코딩 과정을 통해 달라진 점을 솔직하게 기록합니다.

BEFORE 수강 전
  • 😔아이디어는 있지만 구현 방법을 몰라 머릿속에만 담아뒀습니다
  • 😔API가 무엇인지, 어떻게 쓰는지 전혀 알지 못했습니다
  • 😔Next.js, TypeScript 같은 단어는 들어봤지만 시작조차 어려웠습니다
  • 😔서비스를 배포한다는 개념이 막연하게만 느껴졌습니다
  • 😔코딩 없이는 IT 서비스를 만들 수 없다고 생각했습니다
AFTER 수강 후
  • 🎉아이디어를 PRD로 구조화하고 실제 서비스로 구현할 수 있게 됐습니다
  • 🎉NHTSA 공공 API를 직접 연동해 실데이터를 화면에 표시했습니다
  • 🎉Next.js 16 + TypeScript 프로젝트를 처음부터 셋업했습니다
  • 🎉Vercel로 실제 URL을 가진 서비스를 세상에 배포했습니다
  • 🎉바이브코딩으로 하루 만에 MVP를 완성하는 경험을 했습니다
